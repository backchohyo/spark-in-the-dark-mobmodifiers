# MobModifiers

Spark in the Dark 몬스터 강화 모드입니다. 몬스터에게 접두사를 붙이고, 접두사가 붙은 몬스터를 쓰러뜨리면 티어에 따라 장비와 스킬북을 보상으로 줍니다.

[SparkModLoader](../SparkModLoader) 가 필요합니다. [Modifiers](../Modifiers) 가 함께 켜져 있으면 보상 장비에 등급과 유니크가 붙습니다.

## 설치

`release/Mods/MobModifiers.dll` 을 게임 폴더의 `Mods` 폴더에 넣습니다.

## 접두사 (14종)

몬스터가 처음 나타날 때 15% 확률로 접두사가 붙습니다. 다중 접두사가 켜져 있으면 25% 확률로 하나씩 더 붙고, 최대 3개까지 붙습니다. 몬스터의 티어는 붙은 접두사 중 가장 높은 티어입니다.

| 티어 | 접두사 | 기본 효과 |
|---|---|---|
| 1 | 신속한 | 이동 속도 +40%, 공격 속도 +10% |
| 1 | 단단한 | 받는 피해 -35% |
| 1 | 날카로운 | 공격이 맞으면 출혈 |
| 1 | 재생의 | 매초 최대 체력 2% 회복 |
| 1 | 유연한 | 근접 공격 30% 회피 |
| 2 | 거대한 | 체력 +80%, 공격력 +30%, 몸집 1.15배 |
| 2 | 역병의 | 공격이 맞으면 중독 |
| 2 | 흡혈의 | 영웅에게 입힌 피해의 30% 회복 |
| 2 | 가시의 | 영웅이 입힌 피해의 20% 반사 (영웅을 죽이지는 않음) |
| 2 | 어둠의 | 공격이 맞으면 40% 확률로 실명 |
| 2 | 광폭한 | 체력 50% 이하일 때 공격력 +40%, 공격 속도 +30% |
| 3 | 강력한 | 공격력 +80% |
| 3 | 엘리트 | 공격력·체력·이동 속도·방어력 +30% |
| 3 | 불사의 | 처음 쓰러질 때 체력 50%로 한 번 부활 |

## 처치 보상

영웅이 쓰러뜨렸을 때만 줍니다. 시체에 소지품 칸이 있으면 그 안에, 없으면 바닥에 떨어뜨립니다.

| | 장비 | 개수 | 스킬북 | 등급 비중 (빛바랜:은은한:찬란한) | 유니크 |
|---|---|---|---|---|---|
| 1티어 | 50% | 1 | 3% | 45 : 40 : 15 | 1% |
| 2티어 | 85% | 1~2 | 8% | 25 : 45 : 30 | 3% |
| 3티어 | 100% | 2~3 | 20% | 5 : 35 : 60 | 10% |

장비는 현재 층에서 나올 수 있는 무기·갑옷·방패 중에서 고르고, 티어가 높을수록 낡은 장비가 덜 나옵니다. 스킬북은 게임의 상자 규칙(직업, 이미 배운 스킬)을 그대로 따릅니다.

## 머리 위 표시

접두사가 붙은 몬스터 머리 위에 `【거대한 · 역병의】` 처럼 이름표가 뜹니다. 색은 1티어 흰색, 2티어 주황, 3티어 빨강입니다. 체력바도 함께 표시됩니다.

## 설정

게임 메인 메뉴 [모드] > MobModifiers [설정]에서 아래 항목을 바꿀 수 있습니다.

- 접두사 확률, 다중 접두사 허용, 최대 개수
- 이름표·체력바 표시 대상, 거리, 크기
- 접두사별 사용 여부, 등장 비중, 수치
- 티어별 보상

접두사는 세이브에 저장됩니다.

## 빌드

```
dotnet build -c Release
```

게임 폴더의 `Spark in the Dark_Data\Managed` 와 `Mods\ModLoader.dll` 을 참조합니다. 게임이 기본 경로가 아니면 `-p:GameDir="..."` 로 지정합니다.
